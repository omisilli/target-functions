targetFunctions

Open, close and toggle by name.

Every button on this page is plain HTML. The behaviour lives in one attribute: data-pg-target-functions.

Try the commands

  • toggle-menu

    Opens the drawer, or closes it if open.

  • toggle-search

    Drops the search bar from the top.

  • open-menu if-opened-search-close-search

    Opens the menu and closes search, if search was open.

  • close-menu open-search

    Two commands, left to right.

  • if-closed-menu-open-search

    Opens search — but only while the menu is closed.

Each question: close-faq-except-s1 toggle-s1 — close every answer but its own, then flip its own. On a phone, --pg-target-skip: close-faq (in a media query) leaves the close out, so any number stay open. The opening is CSS: a grid row from 0fr to 1fr, nothing measured. Tabs — and an address that opens one

Each tab: close-tab-except-t2 open-t2 — close every panel but its own, then open its own. Open, not toggle: a tab pressed twice stays open. The first panel is written open in the markup, so with no # in the address the first tab shows. With one, the panel of that id opens instead — …/index.html#procedures — through its own tab's commands, so the others close as they would on a click; then the page goes to it. A link on the page to #procedures does the same.

Except — not only for accordions

Three chips, each its own name and all of them chip. Any command may leave some out.

A B C
  • toggle-chip

    Flip all three.

  • toggle-chip-except-a

    Flip B and C; A is left as it is.

  • open-chip-except-b-c

    Open A only.

  • close-chip

    Close them all.

Things to notice

  • Esc closes whatever was opened last.
  • Focus moves into the drawer, and back to your button when it closes.
  • While anything is open, the page behind it does not scroll.
  • The two top-bar buttons light up while their target is open (aria-expanded).
