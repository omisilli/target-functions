targetFunctions

Open, close and toggle by name.

Every button on this page is plain HTML. The behaviour lives in one attribute: data-pg-target-functions.

Try the commands

  • toggle-menu

    Opens the drawer, or closes it if open.

  • toggle-search

    Drops the search bar from the top.

  • open-menu if-opened-search-close-search

    Opens the menu and closes search, if search was open.

  • close-menu open-search

    Two commands, left to right.

  • if-closed-menu-open-search

    Opens search — but only while the menu is closed.

Several names, no scroll lock

A target may carry more than one name. These two answers are each their own faq1 / faq2, and both are also answers — so one command closes them all. They lock nothing: Escape and focus moves are kept for dialog-like targets, so an accordion behaves like an accordion.

Except — not only for accordions

Three chips, each its own name and all of them chip. Any command may leave some out.

A B C
  • toggle-chip

    Flip all three.

  • toggle-chip-except-a

    Flip B and C; A is left as it is.

  • open-chip-except-b-c

    Open A only.

  • close-chip

    Close them all.

Things to notice

  • Esc closes whatever was opened last.
  • Focus moves into the drawer, and back to your button when it closes.
  • While anything is open, the page behind it does not scroll.
  • The two top-bar buttons light up while their target is open (aria-expanded).
